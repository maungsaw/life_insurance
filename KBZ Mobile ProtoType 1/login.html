End-user flow map

Phone = agent UI only. Edge cases appear as natural modals when the system triggers them.

  1. Happy login — Phone + Password → Biometric offer → Home
  2. Register (in Core) — Details → OTP → Create password → Login
  3. Register (not in Core) — Details → pending-review modal (system-driven)
  4. Forgot password — Mobile → OTP → Remark + new PW → Login
  5. Locked — After 5 fails → locked screen
  6. Session block — Modal when another mobile session is active
