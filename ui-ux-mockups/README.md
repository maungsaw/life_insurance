# KBZ LIFE Agent App — UI/UX Mockups

End-to-end UI/UX exploration based on **Business Requirement Document v2.3** (Agency Sales Digital Platform).

## How to view

Open `index.html` in a browser (double-click or serve locally).

```bash
open ui-ux-mockups/index.html
```

Each concept is a clickable prototype: use **top jump chips** or **in-phone navigation** to walk the full journey.

## Covered BRD surfaces

- Web app shell: left menu + header (logo / profile), Dashboard with 5.2.1 metrics + weighting + bar/line charts, CRM, Policies/Sales (FR-03), Tasks (Add/Move/Delete), Announcements, Recruitment, Ops, Audit
- Mobile: Unified auth, dashboards, FR-03 CRM, quoting, e-App stepper, FR-07 tasks, notifications, resources, profile (ENG/MM)
