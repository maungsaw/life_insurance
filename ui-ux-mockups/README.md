# KBZ LIFE Agent App — UI/UX Mockups

End-to-end UI/UX exploration based on **Business Requirement Document v2.3** (Agency Sales Digital Platform).

## How to view

Open `index.html` in a browser (double-click or serve locally).

```bash
open ui-ux-mockups/index.html
```

Each concept is a clickable prototype: use **top jump chips** or **in-phone navigation** to walk the full journey.
