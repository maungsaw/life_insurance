Three new mobile designs — pick a direction

Feedback: the current app looks too similar to Wireframe1 and Wireframe2. We prepared three distinct modern directions — same BRD features, different UI/UX.

Mobile only HTML backup wireframes 45–60 min review BRD v2.3 unchanged

Use ← → arrow keys · Today’s goal: choose Branch 1, 2, 3, or hybrid

Problem

Why this review?

  • Wireframe1/2 patterns: blue hero · 4×2 service grid · bottom nav + center FAB · promo carousel
  • First Flutter build followed these patterns closely
  • Stakeholder feedback: “Still looks like the wireframes” — not a fresh product identity

What we are NOT changing

  • Agent workflows: auth · CRM · quote · e-App · tasks · commission display
  • BRD scope · hierarchy rules · ENG/MM · security
  • Web portal (separate React app)

Option A

Branch 1 · Atelier

Editorial daily planner — warm stone, forest green, terracotta accent.

  • Nav: Top chips (Today · People · Sell · Me) — no bottom bar, no FAB
  • Home: Timeline “Today · N items need you”
  • Guest: Editorial band + horizontal service scroll
  • Best for: Field FA adoption, human feel

Live demo → branch-1-atelier

Option B

Branch 2 · Signal

Dark performance HUD — cockpit for KPI-driven agents and managers.

  • Nav: Left icon rail + command search
  • Home: Bento KPI tiles · sparklines · red-flag strip
  • Guest: Calculator live · glass blur lock on partner tools
  • Best for: Team leads, managers, power users

Live demo → branch-2-signal

Option C

Branch 3 · Grove

Guided trust — soft lilac, wizard auth, next-best-step home.

  • Nav: 3 bottom tabs (Home · Work · Account)
  • Home: “Next best step” hero + 2-col service tiles with subtitles
  • CRM: Qualify checklist on lead detail
  • Best for: Brand trust, new agents, HOA audience

Live demo → branch-3-grove
