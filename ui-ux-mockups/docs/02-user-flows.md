# End-to-End User Flows

## Flow 1 — New / Existing agent authentication
1. Open app → brand splash  
2. Enter mobile → CORE check  
   - Not in CORE / inactive → message + “Contact support / Backend Application List”  
   - Active → continue registration / login  
3. Password + SMS OTP  
4. Optional biometric enroll  
5. Land on role-aware Home  

## Flow 2 — Lead → Quote → e-Application → Policy
1. People → Add Lead  
2. Open lead → Create Quote (or Sell → Product Library)  
3. Premium Calculator stepper (age, sum assured, mode, riders…)  
4. Save Quote linked to lead  
5. Start e-App (pre-fill)  
6. KYC: NRC scan/upload for PH / Insured / Beneficiary  
7. Documents + dual e-signature (client + agent)  
8. Submit → Application Tracker (Draft / Submitted / Mark for Correction / Approved / Rejected)  
9. On approve → Lead converts to Client; Policy appears in Policy Search  

## Flow 3 — Daily servicing loop
1. Home shows “Premium due in 7 days” + “Renewal in 60 days”  
2. Tap alert → Client profile / Policy detail  
3. Call / note / create follow-up task  
4. Mark task complete  

## Flow 4 — Manager coaching
1. Home → toggle **Personal Team** / **Total Group**  
2. Summary card: Actual vs Target (APE, FYP, SFYP, Weighted Freelance FYP)  
3. MDRT tracker table  
4. Tap FA name → Agent performance card  
5. Create coaching / recruitment task (web or mobile per permission)  

## Flow 5 — Web executive oversight
1. Login → Overview (red flags below target %)  
2. Performance → multi-level hierarchy filters  
3. Line-by-line FA table + persistency K1/K2  
4. Export Excel  
5. Ops: announcements (image+URL), notification rules, agent data change audit  

## Flow 6 — Offline
1. Banner: Offline — local only  
2. Allowed: view clients/contacts, brochures, create lead/task  
3. Queued badge on created items  
4. Reconnect → sync toast + conflict handling entry if needed
