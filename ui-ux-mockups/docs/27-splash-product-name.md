# Splash screen — product name & supporting line

**Screen:** Mobile `s-splash`  
**Ask:** Platform title · no subtitle · single **Get started** CTA (no “I already have an account”).

---

## 1. Constraints

| Constraint | Impact |
|------------|--------|
| Logo already says **KBZ LIFE** + tagline | Full product name as H1 needs smaller type |
| Name is **long** | Multi-line ~20px, not 28px “Agent” style |
| Splash job | Brand → enter auth (unified login) |
| Returning vs new | Resolved on **Sign in**, not on splash |

---

## 2. Name placement

**Pick:** Full name as multi-line title (`KBZ LIFE Agency Sales` / `Digital Platform`).

---

## 3. Supporting line

Removed per product ask — splash is logo + name + one CTA only.

---

## 4. CTAs — “I already have an account”

| Option | Idea | Verdict |
|--------|------|---------|
| Two buttons | Get started + I already have an account | Both opened same Sign in → redundant |
| Text link secondary | Softer returning path | Still duplicates Sign in |
| **Single Get started** | One door into login | ✅ **Pick** |

**Why remove:** Splash is not “register vs login.” FR-01 unified login lives on Sign in. Second button added noise and same destination.

**Copy:** “Get started” = *enter the app* (new or returning).

---

## 5. Spacing

**Pick:** Brand upper · CTA lower (`space-between`) · thumb zone.

| Token | Value |
|-------|-------|
| Splash pad | `36px 18px 28px` |
| Logo → title | `22px` |
| Single primary CTA | Full width at bottom |

---

## 6. Acceptance

- [x] Subtitle removed  
- [x] “I already have an account” removed  
- [x] Single **Get started** → Sign in  
- [x] Brand upper · CTA lower
